# Real Estate Web3 Architecture — Brasil (Laboratório)

Este repositório é um laboratório de estudo e estruturação voltado a **governança, risco e conformidade regulatória** para ativos imobiliários com **representação digital** no Brasil.

A proposta é formar competência prática para atuar profissionalmente como **arquiteto de estrutura** (estrutura jurídico-operacional + compliance + governança + requisitos de tecnologia), sem confundir infraestrutura digital com oferta de investimento.

## Objetivo
- Dominar o “mapa do território” regulatório (CVM, BC, Coaf) aplicável a estruturas com ativos imobiliários e representação digital.
- Construir templates e artefatos reutilizáveis: investment memo, relatório mensal, matriz de riscos, checklists e estruturas.
- Montar estudos de caso completos (data room simulado + dossiê) como portfólio técnico.

## Princípios
- **Token não é produto; é infraestrutura.**
- **Governança antes de tecnologia.**
- **Sem captação. Sem promessa de retorno. Sem intermediação.**
- Conformidade regulatória não é “opcional”: é requisito de sobrevivência.

## Escopo (o que este repo cobre)
- Estruturação e governança (SPE/veículos/fluxos/relatórios)
- Noções de valuation pragmático (NOI, cap rate, cenários)
- PLD/FT (KYC/AML) em nível operacional (checklists e processos)
- Wireframes e backlog de um MVP de governança/relatórios

## Fora de escopo (o que NÃO cobre)
- Oferta pública/captação/distribuição ao varejo (execução)
- Custódia/movimentação de recursos de terceiros
- Recomendação de investimento (suitability, aconselhamento)
- Parecer jurídico (sempre exige advogado)

## Status
Work in progress. Documentos evoluem por versão (commits).

## Aviso importante
Este repositório é material educacional e de estruturação técnica.
Não constitui oferta de valores mobiliários, recomendação de investimento ou intermediação financeira.
